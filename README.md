# Airbnb Backend Clone

A scalable backend application inspired by Airbnb, built using Spring Boot.

---

## 🚀 Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate
- Spring Data JPA
- MySQL
- Maven
- Swagger UI

---

## ✨ Features

- User Registration & Login
- JWT Authentication
- Role-based Authorization
- Property Listing APIs
- Booking APIs
- Secure REST APIs
- Exception Handling
- Validation


---

## 🧠 Architecture

- Controller Layer
- Service Layer
- Repository Layer
- DTO Pattern
- Entity Relationship Mapping
